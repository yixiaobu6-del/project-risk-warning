# 项目风险早期预警

项目延期、预算超支总到最后才发现？
**早期预警帮你提前应对风险。**

[![HTML](https://img.shields.io/badge/打开即用-无需安装-orange)]()

## 风险不再"事后诸葛亮"

- **风险矩阵**：概率×影响四象限，一眼看清高危风险
- **处置库**：15条预设处置方案+自定义
- **趋势预测**：线性回归+MA3移动平均，预测风险走向
- **变更通知**：风险等级变化自动通知

## 怎么用

打开 `web_dashboard.html` → 添加风险 → 查看预警
